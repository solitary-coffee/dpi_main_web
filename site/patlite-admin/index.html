PATLITE

積層灯

この PC（Chromebook 可）に USB でつないだ Arduino の積層灯へ、自宅サーバー・AWS の障害と防災情報を表示します。Chrome か Edge で開き、このタブを開いたままにしてください。アプリのインストールは不要です。

読み込み中…
ログインし直す（別のタブで開きます）
「対応デバイスが見つかりません」と出るとき（Chromebook）
  1. Linux 開発環境を使っている場合: 設定 → 詳細設定 → デベロッパー → Linux 開発環境 → USB デバイスを管理 で Arduino をオフにして、挿し直す（Linux に渡っていると Chrome から見えません）。挿したときの「Linux に接続」の通知は押さない。
  2. 「すべての機器から選ぶ」で探す（互換機など、識別番号が違う Arduino の場合）。
  3. それでも出ないときは「WebUSB で接続」を押す（シリアルとしてではなく USB として直接やりとりします。一度選べば次からは自動でつながります）。
  4. chrome://device-log を開いて挿し直し、「USB device added」が出るか確認。出なければケーブル（充電専用ケーブルは不可）か USB の口を変える。
  5. 学校・会社で管理された Chromebook は、管理者の設定で USB シリアルが使えないことがあります。

NOW

いまの積層灯

「試す」は 10 秒間その色を点滅させ、その後は自動表示に戻ります。上の「確認」「強制停止 / 解除」は Arduino のボタンと同じ働きです（ボタンが使えないときの代わり）。Arduino のボタンは、短押しで確認（3秒後にいま点いているものを消す。その間ボタンの LED が赤。復旧の緑は押したらすぐ消える）、2秒以上の長押しで強制停止（全停止の切り替え）です。Arduino は Ver.2.2 以降が必要です（3秒・復旧の緑 5 秒は Ver.2.3）。

自宅のブリッジから届いた項目が出た時刻と消えた時刻です。一時停止・無期限停止・強制停止・時間帯設定・一時的な絞り込みで積層灯に出さなかった項目も記録し、「積層灯」の欄にその理由（例: 「一時停止により無連動」）を出します（理由は項目が出た時点の設定で決めます）。「監視の途絶」は、ブリッジからの送信が 3 分以上途切れた時間帯です。90 日分を残します。

LEGEND

色の一覧

赤＝配信が止まる重大障害、黄＝一部の障害・注意、青＝AWS 側・監視の途絶、白＝防災情報（重大なものは 白＋赤・白＋黄 の 2 色）、緑＝復旧。正常なときは消灯。障害は最長 5 分点けたら一旦消し、30 分空けてまだ続いていればまた点けます（時間は「表示の設定」で変更）。防災情報は最長 5 分か確認まで点けたら、同じ情報ではもう点けません（津波注意報→津波警報のように種類が変わったら、また点けます）。重なったときは色を合わせて点け、点滅は色ごと。確認（物理ボタンの短押し・この画面・操作盤）で、3 秒後にいま点いている項目を消します（復旧の緑はすぐ消えます）。2秒以上の長押しで強制停止／解除。ブザーは使いません。色見本の点滅しているものは、積層灯でも点滅します。

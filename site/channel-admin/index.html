配信先検索

SERVER & CHANNEL DIRECTORY

サーバー・チャンネルを検索

サーバー名、チャンネル名、各ID、配信名から横断検索できます。

配信名（複数可）

チャンネル種別・申請の有無で絞り込めます。一括取得後は、Discordから取得した最新のサーバー名・チャンネル名・種別も検索に使用します。最大件数を選択しない場合は全件表示します。Webhook URLや認証情報は表示しません。

検索後に利用できます。

種別をまとめて再判定する場合は、チャンネル種別を「すべて」にして検索してから実行してください。取得できないサーバーはスキップして次のサーバーを処理します。

検索条件を入力してください

サーバー名やID、配信名から配信先を確認できます。
